# Claude Client

An open-source Fabric utility client for **Minecraft 1.21.11**: seed tools (hashed seed, ore prediction from the
world seed, biome and structure finder, seed map), base finders and ESPs, freecam, freelook and speed mine.

> **Unofficial.** Claude Client is a fan project. It isn't made by, affiliated with or endorsed by Anthropic or Mojang.
> Many servers ban ESPs, freecam and similar tools. What you run on a server is your responsibility.

## Install

1. Install [Fabric Loader](https://fabricmc.net/use/) 0.19.3+ for Minecraft 1.21.11 and [Fabric API](https://modrinth.com/mod/fabric-api).
2. Download `claude-client-<version>.jar` from [Releases](../../releases) and put it in your `mods` folder.
3. In game, press **Right Shift** to open the menu (rebindable in Controls). Right-click a module to toggle it.
   Every module has its own keybind setting.

## Modules

### Seed

| Module | What it does |
| --- | --- |
| **Hashed Seed** | Reads the hashed seed the server sends on join and dimension change. Click-to-copy in chat, Copy buttons in the menu, a keybind, `/claude seed copy`, and a history of every seed you've seen. |
| **Seed ESP** | Every ore from the world seed: diamonds, ancient debris, emeralds, gold, iron, redstone, lapis, copper, coal, nether gold, quartz, and the big raw iron/copper ore veins. Works at any depth, and anti-xray and anti-freecam can't hide anything from it, because nothing is read from the server's blocks. |
| **Seed Biome Checker** | The exact biome you're in and the trees it grows; the nearest villages, temples, monuments, mansions, outposts, ruined portals, shipwrecks, ocean ruins, buried treasure, mineshafts, strongholds, ancient cities, trial chambers, trail ruins, fortresses, bastions and end cities with copyable coordinates and in-world markers; find the nearest biome of any type; slime chunks. `/claude map` opens a seed map (drag, zoom, click a structure to copy it). |

The seed modules need the real world seed, which servers never send. Set it once per server with
`/claude seed set <seed>`. In singleplayer it's read automatically. The server's hashed seed can't be turned back
into the seed, but it does prove a seed is right, so the client checks every seed you enter against it.

#### How Seed ESP works, and how accurate it is

Seed ESP doesn't approximate ore generation. It loads the worldgen registries from the vanilla data pack inside the
game jar, the way a server does. Then it runs Minecraft's own chunk pipeline for your seed in background threads:
biomes, noise (terrain, aquifers, ore veins), surface, carvers (caves and canyons), and vanilla's own feature code
with the server's exact per-feature random seeds (lakes, geodes, dungeons, ores...). A small stand-in for the
server's `WorldGenRegion` lets that vanilla code run without a server.

Tested against a 1.21.11 singleplayer world (integrated server = ground truth):

| Check | Result |
| --- | --- |
| Biomes (867 sample points) | 100% match |
| Terrain and caves, air vs solid (30,720 cells) | 100% match |
| Predicted ores that are real (precision) | 100% (3058 / 3058) |
| Real ores that were predicted (recall) | 99.97% (3058 / 3059) |
| Diamonds | 244 predicted, 244 real, 244 matched |
| Structures found within 24 chunks that really exist | 22 / 22 |
| Nearest village / stronghold vs the server's `/locate` | match |

It's exact for chunks a 1.21.11 server generated from that seed. It can be off right next to structures
(mineshafts and ancient cities aren't placed in the simulation), in chunks generated by older Minecraft versions,
and on servers with custom worldgen datapacks. Wherever your client can see real ores, the menu shows the live
match rate.

### Finders

| Module | What it does |
| --- | --- |
| **Storage ESP** | Chests, trapped chests, ender chests, barrels, shulkers, hoppers, dispensers, furnaces and more, through walls, at any distance, kept after chunks unload. **Light Storage** reads the server's light data for hidden light sources as bright as an ender chest (7) or a lit furnace (13) where the visible block gives off no light. |
| **Player ESP** | Boxes, tracers and name tags (distance, health), plus "last seen" markers when a player leaves tracking range. |
| **Sus Chunks** | Scores chunks for signs of players: rotated deepslate, player blocks underground (ignoring the ones trial chambers and ancient cities generate), hidden light, fresh digging, long-loaded growth. |
| **Farm Debug** | Flags farms and working bases from blocks (crops, cane, kelp, bamboo, cactus, wart, stems, redstone, hoppers, spawners, bubble columns), entities (items and XP piling up, villagers, golems, mob crowds) and live activity (growth, pistons, dispensers, items appearing, mobs dying). |
| **Light Finder** | A yellow overlay of every lit space, from the server's light data rather than its blocks. **Hidden Light** mode shows only light inside blocks that fully stop light, which is impossible in a real world, so it marks spaces the server is hiding. Marks light sources with their brightness. |
| **Sound ESP** | Red boxes where the server reports base-like noise: pistons, redstone, minecarts, doors, chests, anvils/brewing, farms, mobs, other players' movement. Ignores your own sounds. |
| **Armor Stand Bypass** | Shows armor stands' real shape through blocks, never hides them for distance, and labels what they're wearing and holding. |

**What "works through anti-freecam" can and can't mean:** a client can only use what the server sends.
- Light data, block updates, block events and sounds often still come through when blocks are hidden, and the
  finders use all of those.
- Seed ESP and the Biome Checker don't depend on the server at all.
- Things a server never sends can't be shown by any client: entities it withholds, sounds beyond its send range
  (normally about 16 blocks for sounds and 64 blocks for block events like pistons, doors and chests).

Found markers stay on screen at any distance. Boxes past the camera's far plane are pulled in along the line of
sight so they never get clipped.

### Player

| Module | What it does |
| --- | --- |
| **Freecam** | Fly the camera anywhere. **Keep Moving**: the movement keys you were holding when you turned it on stay held for your player, so it keeps walking, jumping or sneaking. **Keep Mining**: holding attack keeps mining what your player is looking at. Camera keys never move your player. |
| **Freelook** | Look around without turning your player (hold Left Alt by default). |
| **Speed Mine** | Client-side Haste with an adjustable level. **Speed Haste** gives you a real client-side Haste effect. **Server Safe Haste** caps your speed at what a vanilla/Paper server accepts (it re-checks breaks at 70% progress), and never turns a block into an instant break the server would refuse. |

### Client

**HUD**: watermark, module list, info lines (hashed seed, biome, trees, slime chunk).

## Commands

```
/claude                       help
/claude seed                  hashed seed(s) with [Copy]
/claude seed copy             copy the current hashed seed
/claude seed set <seed>       real world seed for this server (checked against the hashed seed)
/claude seed world            show the saved world seed and whether it checks out
/claude seed clear            forget this server's world seed
/claude map                   seed map
/claude menu                  open the menu
/claude toggle <module>       turn a module on or off
```

## Building

Requires JDK 25 to run Gradle (Fabric Loom); the mod targets Java 21.

```
./gradlew build          # jar in build/libs/
```

If JDK 25 isn't your default Java, set `JAVA_HOME` to it first.
